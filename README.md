# سارا وێنە — سیستەمی تۆماری ئۆتۆمبێل (Sara Wena Mobile Web App)

سیستەمی پێشکەوتووی تۆمارکردن، پشکنین و بەڕێوەبردنی ئۆتۆمبێل بە بەکارهێنانی Microsoft SQL Server و تەکنەلۆژیای سەردەمی وێب و ئەپڵیکەیشنی مۆبایل (PWA).

---

## 🌟 تایبەتمەندییە سەرەکییەکان
- **Mobile Responsive & PWA**: بە تەواوی بۆ مۆبایل و تابلێت ئامادەکراوە و بە دوگمەی «📲 داگرتنی ئەپ» دەخرێتە سەر شاشەی مۆبایل وەک ئەپڵیکەیشن.
- **Offline & Cache Resilience**: خاوەنی Service Worker و خێرایی زۆر بەرزە.
- **Cloudflare Global Tunnel**: بە بەکارهێنانی `start-cloudflare-tunnel.bat` بە یەک کلیک بەستەری پارێزراوی جیهانی HTTPS دروست دەبێت و بە خۆکاری کۆپی دەبێتە ناو کلیپبۆرد و لە وێبگەڕدا دەکرێتەوە.
- **SQL Server Connection**: بەستراوە بە بنکەی دراوەی تاقیگەی پارێزراو.

---

## 🚀 چۆنیەتی کارپێکردن بۆ مۆبایل
1. دوو کلیک لەسەر فایلی `start-cloudflare-tunnel.bat` بکە.
2. بەستەرە جیهانییەکە دەردەکەوێت و ڕاستەوخۆ دەتوانیت بینێریت بۆ هەر مۆبایلێک.
